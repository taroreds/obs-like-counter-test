# 高評価ゴール OBSウィジェット

## 1. ツールの概要

OBSのBrowser Sourceへ高評価などの進捗を表示し、OBS内のカスタムブラウザドックから現在値と目標値を操作する軽量なウィジェットです。

外部ライブラリ、Node.js、Webサーバー、OBS WebSocketは使用しません。

## 2. 対応する操作

controllerでは、次の操作ができます。

* 現在値を `-10`、`-1`、`+1`、`+10` する
* 現在値を直接設定する
* 目標値を直接設定する
* 現在値だけを0に戻す
* 現在値、目標値、表示内容を初期設定へ戻す
* 表示ページとの再同期を要求する

## 3. 導入前の注意

配布フォルダは、移動や削除しない安定した場所へ展開してください。OBSへ登録した後にフォルダを移動・名前変更すると、登録済みのfile URLが無効になります。

`index.html` と `controller.html` は同じ配布フォルダから読み込む必要があります。日本語や空白を含むパスは環境差の検証が必要なため、可能であれば短く単純な英数字のパスを推奨します。

Windowsパスをfile URLへ変換する例です。

```text
C:\OBS Tools\Like Goal\index.html
↓
file:///C:/OBS%20Tools/Like%20Goal/index.html
```

空白は `%20` に置き換えます。日本語を含むパスのエンコード方法は環境により確認してください。

## 4. Browser Sourceの追加手順

1. OBSで表示したいシーンを開きます。
2. Browser Sourceを追加します。
3. 「ローカルファイル」を無効にします。
4. URL欄へ `index.html` のfile URLを入力します。
5. 幅を1920、高さを1080に設定します。
6. 表示位置は `config.js` の設定に従います。

## 5. カスタムブラウザドックの追加手順

1. OBSの「表示」→「ドック」→「カスタムブラウザドック」を開きます。
2. 任意の名前を入力します。例：`高評価ゴール操作`。
3. URL欄へ `controller.html` のfile URLを入力します。
4. 追加したドックを表示します。
5. 状態が「同期済み」になるまで待ちます。

同期済みになるまで、controllerの操作は無効です。

## 6. 値の操作方法

増減ボタン、直接設定、リセットボタンを使います。直接設定では、空文字や有限数に変換できない値はcontroller内にエラーとして表示されます。小数は入力できますが、表示ページのstate仕様に従って小数点以下が切り捨てられます。

「初期設定に戻す」は確認ダイアログを承認した場合だけ送信されます。OBSドックでこの確認ダイアログが機能するかは、導入後に確認してください。

## 7. 再読み込みと再起動

永続化は行いません。Browser Sourceの更新やOBS再起動後、実行時状態は`config.js`の検証済み初期値へ戻ります。controllerは表示ページからstateを受信した時点で表示を更新します。

controllerを再読み込みした場合は、自動的に再同期要求を送信します。必要に応じてcontrollerの「再同期」ボタンを使ってください。

## 8. 対応構成と通信不能時の確認

正式対応は、表示ページ1つとcontroller1つです。複数表示ページでは状態競合を防止しないため、使用しないでください。

controllerが「未接続」または「同期待機」のままの場合は、次を確認します。

* Browser Sourceとcontrollerの両方が同じ配布フォルダ内のfile URLを参照しているか
* Browser Sourceで「ローカルファイル」が無効か
* URLの空白や特殊文字が正しくエンコードされているか
* Browser Sourceを更新後、controllerで「再同期」を押したか
* OBSの再起動後に同じ症状が再現するか

通信不能でも、表示ウィジェット自体は`config.js`の初期設定で表示を継続します。

## 9. 技術的制約

通信にはBroadcastChannelを使用します。同期済みは、有効なstateを最後に受信したことを示すだけで、表示ページが現在も存在することや切断されていないことを保証しません。heartbeat、接続タイムアウト、永続化、OBS WebSocketは実装していません。

## 10. アンインストール

1. OBSのBrowser Sourceを削除します。
2. 「表示」→「ドック」からカスタムブラウザドックを削除します。
3. 必要であれば配布フォルダを削除します。
